# Kursmaterial

Unterlagen und Übungen aus unserem Kurs – einfach erklärt.

- **Bewerbung auf Knopfdruck:** Serienbrief mit Excel und Word. Aus einer Liste werden mit einem Klick fertige
  Bewerbungsanschreiben. Die Dateien liegen in [`materials/serienbrief`](materials/serienbrief).
- **Unterlagen:** Arbeitsblätter aus dem Kurs als kurze Artikel, mit Suche. Die Texte liegen in
  [`site/content/unterlagen`](site/content/unterlagen).

## Website bauen

```bash
python3 site/build.py   # braucht pandoc und PyYAML; Ergebnis in site/dist/
```
