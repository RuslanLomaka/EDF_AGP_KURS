2. Das Wichtigste in Kürze

Diese Website ist ein reines Leseangebot. Es gibt keine Konten, keine Formulare, keine Cookies von uns, kein Tracking und keine Analyse-Werkzeuge. Wir selbst erheben und speichern keine personenbezogenen Daten.

Die Seiten werden über GitHub Pages ausgeliefert, einen Dienst der GitHub, Inc. (88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA). Dabei verarbeitet GitHub technisch notwendige Verbindungsdaten, insbesondere Ihre IP-Adresse, Datum und Uhrzeit des Abrufs, die aufgerufene Adresse sowie Angaben zu Browser und Betriebssystem. GitHub speichert die IP-Adresse aus Sicherheitsgründen in Protokollen. Das ist nötig, um die Seiten auszuliefern und den Dienst vor Angriffen zu schützen.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Unser berechtigtes Interesse ist eine sichere und zuverlässige Bereitstellung der Website. GitHub kann Daten auch in den USA verarbeiten. GitHub ist nach dem EU-US Data Privacy Framework zertifiziert; dafür gilt der Angemessenheitsbeschluss der EU-Kommission (Art. 45 DSGVO).

4. Kein eigener Webserver

Für diese Adresse betreiben wir keinen eigenen Server. Wir erhalten von GitHub keine Zugriffsprotokolle und speichern selbst keine IP-Adressen.

5. Speicherung in Ihrem Browser

Zwei kleine Angaben werden nur in Ihrem Browser gespeichert und nie an uns übertragen:

  • Fortschritt in Lektionen (welche Schritte Sie abgehakt, welche Übungen Sie gelöst und welche Abschnitte Sie als erledigt markiert haben, dazu die Zahl der erledigten Aufgaben für die Übersicht auf der Startseite) im „Local Storage“ Ihres Browsers. Sie können ihn auf der Lektionsseite mit „Fortschritt zurücksetzen“ oder in den Einstellungen Ihres Browsers löschen.
  • Ob Sie den kurzen Hinweis heute schon gesehen haben: nur das heutige Datum, im „Local Storage“. An einem neuen Tag erscheint der Hinweis einmal wieder.

Diese Speicherung ist für die Funktionen, die Sie selbst nutzen, unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG). Suche und Quiz speichern nichts.

6. Vorlesen

Die Aussprache der Wörter wurde vorab aufgenommen und wird zusammen mit der Website geladen. Fehlt eine Aufnahme, liest eine Stimme vor, die auf Ihrem Gerät installiert ist. Ganze Abschnitte liest nur eine Stimme auf Ihrem Gerät vor; gibt es keine, erscheint der Knopf nicht. Dabei werden keine Daten an andere Anbieter übertragen.
