Hinweise & Datenschutz

  • Diese Website ist nur zum Lesen und Lernen da.
  • Sie brauchen kein Konto. Wir sammeln und speichern keine persönlichen Daten, setzen keine Cookies, nutzen kein Tracking und schicken keine E-Mails oder Werbung.
  • Was Sie hier tun – Suche, Quiz, Haken in Lektionen –, bleibt in Ihrem Browser und wird nicht an uns gesendet.
  • Die Inhalte erklären öffentlich zugängliche Informationen, zum Beispiel Gesetze, in einfacher Sprache. Sie ersetzen keine Rechtsberatung.
  • Die Website enthält keine persönlichen oder vertraulichen Daten über Menschen, Firmen oder andere Organisationen. Namen in Beispielen sind erfunden.

Was in Ihrem Browser bleibt

  • Fortschritt in Lektionen: Haken, gelöste Übungen und erledigte Abschnitte werden nur auf Ihrem Gerät gespeichert (im Speicher Ihres Browsers). Sie können ihn mit „Fortschritt zurücksetzen“ oder über die Einstellungen Ihres Browsers löschen.
  • Der kurze Hinweis unten auf der Seite: Ihr Browser merkt sich nur das heutige Datum, damit der Hinweis einmal am Tag erscheint.
  • Suche und Quiz: Es wird nichts gespeichert.

Technik

  • Die Seiten werden über GitHub Pages ausgeliefert (GitHub, Inc., USA). Dabei werden technisch nötige Verbindungsdaten verarbeitet; GitHub speichert die IP-Adresse aus Sicherheitsgründen in Protokollen.
  • Wir selbst erhalten keine Zugriffsprotokolle und speichern keine IP-Adressen.
  • Vorlesen: Die Wörter wurden vorab aufgenommen und werden mit der Website geladen. Fehlt eine Aufnahme, liest eine Stimme vor, die auf Ihrem Gerät installiert ist. Ganze Abschnitte liest nur eine Stimme auf Ihrem Gerät vor. Es werden keine Texte an andere Dienste geschickt.
