Arbeitsrecht

7 Artikel zu diesem Thema.

Serie „Rund um die Kündigung“

  1. Kündigung – einfach erklärt
    Eine Kündigung beendet den Arbeitsvertrag. Es gibt verschiedene Arten und Gründe, und der Arbeitgeber muss Fristen einhalten: Je länger Sie in der Firma sind, desto länger ist die Frist.
  2. Kündigung im Briefkasten: So schützt Sie das Kündigungsschutzgesetz
    Das Kündigungsschutzgesetz schützt vor einer Kündigung ohne guten Grund – wenn Sie länger als 6 Monate in einer Firma mit mehr als 10 Beschäftigten arbeiten. Wer sich wehren will, muss innerhalb von 3 Wochen klagen.
  3. Abmahnung im Job: die gelbe Karte
    Eine Abmahnung ist wie die gelbe Karte im Fußball: eine Warnung vor der Kündigung. Sie muss das Fehlverhalten genau beschreiben und klar sagen, was bei einer Wiederholung droht.
