# Entwürfe (Warteschlange)

Notizen zu Kurs-Arbeitsblättern, die noch keine Artikel sind – in eigenen Worten, damit die Arbeit nicht von
Fotos im Chat abhängt. Wird nicht auf der Website veröffentlicht. Sobald ein Artikel fertig ist, wird seine Notiz
gelöscht. Alle Blätter dieser Runde: datum "2026-11-01", reihenfolge = Dateinummer + 2 (1 bis 5 sind schon veröffentlicht).
